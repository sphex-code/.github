## Sphex — Deterministic Control Infrastructure for Autonomous AI

Autonomous AI agents are increasingly granted production credentials, API tokens, and tool execution privileges—yet existing defenses rely on probabilistic prompt filters and LLM-as-a-judge guardrails that fail under adversarial pressure.

Founded by former research leaders from the **Microsoft AI Red Team** and **Microsoft Research**, Sphex replaces probabilistic guesswork with active, deterministic runtime enforcement grounded in formal **Information-Flow Control (IFC)**.

### The Sphex Deterministic Engine™
* **Sphex APX (Hunt):** Autonomous reinforcement-learned red-teaming to uncover multi-turn exploit chains and systemic vulnerabilities.
* **Sphex NXS (Secure):** Low-latency inline runtime policy enforcement across agent tool calls and MCP integrations—no agent code changes required.
* **Sphex TRC (Track):** Tamper-evident execution ledger and policy replay mapped to EU AI Act, SOC 2, and DORA compliance frameworks.
